# Agent Skills for Healthcare & Life Sciences

A curated collection of agent skills for healthcare and life sciences (HCLS)
workflows, following the [Agent Skills open standard](https://agentskills.io).
The skills come in two flavours — **reasoning skills** that encode methodology
and decision frameworks, and **pipeline skills** that encode tool-specific
commands and code patterns — and they work across 20+ AI agent platforms
including Kiro, Amazon Quick, Claude Code, and OpenAI Codex.

This site hosts the hands-on workshop. Pick a door:

- **[Take the workshop](workshop/overview.md)** — a 90-minute, copy-paste-driven
  lab where you *use* skills on real R&D questions, *extend* one with your own
  org knowledge, and *evaluate* whether your changes actually help.
- **[Browse the 42 skills](https://github.com/awslabs/hcls-agent-skills#skill-catalog)** —
  the full skill catalog, installation instructions, and source live in the
  GitHub repository.

New to the workshop? Start with the
